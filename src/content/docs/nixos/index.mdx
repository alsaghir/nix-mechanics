This track assumes the foundations:
[Start here](/start-here/), [Seeing what Nix sees](/seeing-what-nix-sees/)
and [Reading errors and tracing](/reading-errors/).

On NixOS, the system itself (packages, services, users, boot) is built from
your configuration in `/etc/nixos`. You don't change the system by hand: you
change the configuration, check it, and rebuild. Every rebuild keeps the
previous system, so every change can be undone.
