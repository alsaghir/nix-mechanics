## How the check works

Every `NAME.nix` example has exactly one expectation next to it:

- **`NAME.expected.nix`**: the value `nix eval --file NAME.nix` prints. Line
  breaks and spacing may differ; the value is the same. The check imports
  both files and compares them.
- **`NAME.expected-error`**: lines that must appear in the error output.
  The check runs `nix eval` and fails if it succeeds or if any line is missing.

`nix flake check` runs both kinds and prints the expected and actual output
when something differs. An example without an expectation also fails the
check, so nothing on this site is shown unverified.
